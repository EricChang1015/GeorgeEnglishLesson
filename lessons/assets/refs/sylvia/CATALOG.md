## How agents should pick refs

1. **Sylvia face / likeness (required for any Sylvia art):** start with `priority: primary` — `sylvia-solo-outdoors-graduation-smile.jpg` (front-facing, glasses, smile).
2. **Strong alternate face (no cap):** `sylvia-solo-indoor-selfie-smile.jpg` (front-facing; **no glasses** in this photo — add glasses per lesson bible).
3. **Outdoor / travel / adventure:** `sylvia-solo-outdoors-waterfall-peace-sign-smile.jpg` (joyful, peace sign).
4. **Full-body proportions:** `sylvia-solo-outdoors-park-cinnamoroll-fullbody-neutral.jpg`.
5. **With George / Daddy / family:** use `lessons/assets/refs/george/CATALOG.md` group entries.
6. **Lesson-specific costume locks** (cave kit, T-rex family scene, etc.) stay in chapter bibles — do not copy casual photo clothes unless the beat needs them.
7. Read the photo with the Read tool before generating art; keep likeness consistent across a lesson.
8. Never copy a photo into a published lesson page; generate new picture-book illustrations inspired by these refs.
