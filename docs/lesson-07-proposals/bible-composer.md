**標題：** *George and the Still-Hot Supper* — 角色／比例／場景鎖  
**狀態：** 2026-09-01 — Round 2 bible（劇情與名字已凍結；本檔只鎖外形／比例／Zone／prompt）

## 本 bible 賣點（四行）

1. **全課 George 一套 T-rex 連身裝不脫**——正面／側面／背板／粗尾／深藍運動鞋依家長 Halloween 照片鎖死，p12 仍戴頭套，視覺連續性一眼可驗。
2. **RealBedroom 錨點逐頁可數**——米色軟墊床頭、奶油被、淡藍床單、拳頭大光鳥燈、遠牆灰簾、床頭左實牆無窗；叢林／船變形時至少留一項，回家頁與 p3 同一張床。
3. **三隻野獸 Sendak 氣氛、原創外形**——黃眼／毛／角／爪／溫暖童書尺度；Bramble／Puddle／Thistle 輪廓與配色互不重複，禁止複製 Carol 等原書角色。
4. **小私人 Billy o' Tea ＋ 居家家人比例**——船身茶棕、茶葉帆徽（無英文）、無 crew；家人穿 HOME 便服、身高 Daddy ＞ Sylvia ＞ Mummy ＞ George，與 L5 洞穴裝備完全分離。

## 角色鎖

### George（`george`）— 全 12 頁同一套 T-rex 連身裝

**臉（頭套可上可略露瀏海，但仍是同一張臉）：** 東亞男孩約 5 歲；短黑瀏海、圓臉、大眼、笑時露齒。Ref：`lessons/assets/refs/george/george-solo-bed-smile.jpg`

**T-rex 連身裝（p1–p12 禁止換裝、禁止脫頭套）：**

| 部位 | 鎖定（依家長 ref） |
|------|-------------------|
| 底色／紋理 | 淺卡其／淺橘褐底＋**黑色龜裂鱗紋**；手臂外側、腿外側、頭套頂部有**深紅褐大色塊** |
| 頭套 | 恐龍頭罩在頭頂；圓鼻、頭套兩側各一顆**小圓黑珠眼**；前緣一排**白色軟毛氈小牙**；正面 ref：`george-solo-halloween-trex-bucket.jpg` |
| 背板 | 沿脊椎（頭套→尾尖）一排**深褐三角軟背板**；側面 ref：`george-solo-halloween-trex-night-side.png` |
| 尾巴 | **粗長填充尾**，幾乎及地，與背板連續 |
| 前襟 | 胸前拉鍊（連身衣，非分體） |
| 手 | 袖口外側**白色軟爪**（氈三角） |
| 鞋 | **深藍運動鞋**、白底、側面可有**青綠勾**（Nike 感即可，不要 logo 字） |
| 禁止 | 南瓜桶、換睡衣、脫頭套、金髮、另一張臉 |

**道具：** 圓鈍**木／玩具叉**（play fork）；p7–10 垂下或放苔上，不指向野獸；p11 拾回；p12 靠床邊。

### Bramble（`bramble`）— 野獸 1：挑戰者

| 項目 | 鎖定 |
|------|------|
| 個性（劇情） | 先**亮爪**挑戰，再**第一個低頭** |
| 輪廓 | **最高、最瘦長**的一隻；駝背略弓、長臂過膝 |
| 毛／皮 | **深褐夾灰**粗短毛，肩頸**豎起鬃毛**像乾草 |
| 角 | **一對向前彎的暗角**，像枯枝（非牛魔王式直 horn） |
| 眼／牙／爪 | **琥珀黃圓眼**（黑瞳）；**上犬齒外露**但不滴涎；手／腳**三指長爪**，p7 可舉爪示威，p8 收起 |
| 與他獸差異 | 最兇相、最高；**無尾鰭、無長鼻** |
| 禁止 | 複製 Sendak「牛頭」Wild Thing、額外第四獸 |

**一句外形：** 像長臂枯枝角的棕灰鬃毛野獸，黃眼先亮爪再低頭。

### Puddle（`puddle`）— 野獸 2：好奇嘴饞

| 項目 | 鎖定 |
|------|------|
| 個性（劇情） | 好奇、嘴饞；用**食物**把「想家」問出來 |
| 輪廓 | **最圓、最矮**（仍遠高於 George）；**大肚、短腿** |
| 毛／皮 | **苔綠＋濕褐**相間，像剛踩過水窪的絨毛（「Puddle」視覺雙關，非真實水坑裝置） |
| 角 | **兩根短鈍角**，像小樹杈，向兩側開 |
| 眼／牙／爪 | **黃眼**更大更圓；**小獠牙**；爪較短圓，常捧**島上野果** |
| 與他獸差異 | 唯一**綠調**、唯一**圓胖**；不拿武器 |
| 禁止 | 與 Bramble 同色、複製 Sendak 鳥嘴獸 |

**一句外形：** 苔綠絨毛圓肚野獸，短杈角、大黃眼，手裡常捧島果。

### Thistle（`thistle`）— 野獸 3：加冕／交冠

| 項目 | 鎖定 |
|------|------|
| 個性（劇情） | **加冕**；p11 **接回葉冠** |
| 輪廓 | **中等身高、肩寬**；頸長，站姿端正 |
| 毛／皮 | **紫灰＋淡紫**長毛；頸部有一圈**尖刺狀鬣**（像薊花，非刺蝟針） |
| 角 | **冠状分叉角**（三岔），像乾薊花頭 |
| 眼／牙／爪 | **窄長黃眼**；牙較少露；爪修長，**捧／調整葉藤冠** |
| 與他獸差異 | 唯一**紫調**、唯一**冠形角**；儀式感最強 |
| 禁止 | 複製 Sendak 帶冠獅身獸、冠上英文 |

**一句外形：** 紫灰長毛、薊冠分叉角，窄黃眼，儀式感地捧葉藤冠。

## 比例尺（Scale lock）

**基準：** 站立 George（T-rex 連身裝＋深藍運動鞋）≈ **100 單位**（~5 歲男童）。

### 家人（HOME 便服，站立群像 p12 必成立）

| 角色 | 相對 George 身高 | 身體錨點（George 站立時） | 不要變成 |
|------|------------------|---------------------------|----------|
| **George** | **100**（基準） | — | 另一張臉、脫 T-rex |
| **Mummy** | **~145–155** | George 頭頂約到 Mummy **上腹／腰下** | 比 Sylvia 高 |
| **Sylvia** | **~165–175** | George 頭頂約到 Sylvia **胸口** | 與 George 同高、幼童化 |
| **Daddy** | **~185–195**（全家最高） | George 頭頂約到 Daddy **腰帶／腰際**；比 Mummy **高出一截** | 彎腰縮成與 Mummy 同高 |

**身高順序（硬）：** Daddy ＞ Sylvia ＞ Mummy ＞ George。

### 野獸（相對 George）

| 角色 | 相對 George 身高 | 身體錨點 | 備註 |
|------|------------------|----------|------|
| **Bramble** | **~280–300**（最高獸） | George 頭頂 ≈ Bramble **小腿中段**；Bramble 彎腰時鼻尖可對 George 頭頂 | p7 舉爪時爪尖約 George **肩／胸**高 |
| **Puddle** | **~240–260**（最矮獸） | George 頭頂 ≈ Puddle **膝蓋下／脛** | 肚圍 ≈ George **身寬 2.5 倍** |
| **Thistle** | **~260–280** | George 頭頂 ≈ Thistle **膝上／大腿中** | 加冠時手可及 George 頭套頂 |

**獸 vs 人：** 三獸**皆遠高於 Daddy**（Daddy 頭頂 ≈ 獸**膝～小腿**）；George 與獸並立時，獸是**巨人感**但姿態溫和。

### 船與房間錨

| 物件 | 相對 George |
|------|-------------|
| 光鳥燈 | 高度 ≈ George **拳頭／腳踝** |
| 小 Billy o' Tea | 船長 ≈ George **3.5×**；桅高 ≈ George **5×**；p5 可貼床尾，George **一步跨上** |
| 床（RealBedroom） | 床面 ≈ George **膝～腰**；床頭米色軟墊 ≈ George **坐高 + 一頭** |

## 禁止清單（Forbidden）

### 角色／外形
- George **換裝、脫 T-rex 頭套**（含 p12）
- **第六隸**、野獸**分身**、同一獸複製成不同名
- **1:1 複製** Sendak《Where the Wild Things Are》角色（Carol 等）或原句（*I'll eat you up*、*let the wild rumpus start* 整句）
- 家人穿 **L5 洞穴裝**（頭盔、雨鞋、harness）
- **Mummy 比 Sylvia 高**；**Daddy 非最高**
- 南瓜桶（本課預設不要）
- Mike、Nibble、Pip、Ember 入畫

### 道具／動作
- 木叉**刺人、流血**；p7+ **叉指野獸**
- p8–10 **打鬥**馴服（只用**眼神**）
- 葉冠**跟回家**（p12 無冠）
- 野獸或船**留在 p12 房間**

### 場景
- RealBedroom：**星形燈、床頭櫃檯燈、床頭左側窗／簾**
- p4–5：**床／燈／灰簾錨全消失**
- Billy o' Tea：**換色、換圖徽、Wellerman 造型、crew、鯨**
- 帆或冠上**任何英文**
- p1–2 畫成 **L4 睡房**
- 角色說 **"I am dreaming"**

### 畫面
- 圖上**英文正文**（課文由 player 顯示）
- 寫實照片臉、3D 電影風、恐怖陰影、血
