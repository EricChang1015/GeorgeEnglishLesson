# 匿名劇本投票規則

只讀本資料夾的 `plot-A.md`～`plot-D.md` 與 `docs/lesson-07-brief.md`。  
**不要**讀 `docs/lesson-07-proposals/plot-*.md`、`plot-compare.md`、`plot-working.md` 或任何標了模型名的檔。

四份都是完整 12 頁 Lesson 7。請當獨立評審，**不必投自己可能寫過的那份**；哪份對 5 歲 ORT LV6 繪本最好就投哪份。

## 評分看這幾項（一樣重）

1. 因果：鬧→罰→叢林→船→馴服→狂歡→想家→熱晚飯，有沒有跳或重複
2. 對白：8–16 字、每頁 3–4 句、emotion 清楚、可朗讀
3. 溫暖：木叉玩鬧不恐怖；回嘴成立但不傷人
4. 圖文契約：每頁必見證據是否畫得出來、道具連續
5. 原創：無 Sendak 原句／原角色名
6. 角色開口：Mummy、Sylvia、每隻具名野獸都有台詞

## 投票

只能投 **第一名** 與 **第二名**（兩個不同字母）。不要並列。

寫入指定的 `vote-*.md`，格式：

```markdown
# Vote

- first: X
- second: Y
- first_why: （一句中文或英文，只講文本證據）
- second_why: （一句）
- not_chosen: （各一句：另外兩份輸在哪）
```
