## Checklist

| 項目 | 判定 | 證據 |
|------|------|------|
| 與 p1 相同的 LivingRoom（沙發／燈／地毯） | **PASS** | 畫面左側保留同一組米色沙發，中間有暖色立燈，地面有同款條紋地毯與木地板；右側新增通往房間的門，仍是同一客廳。 |
| Mummy 細框眼鏡、深色長袖、米色褲 | **PASS** | Mummy 戴細框眼鏡，穿深色素面長袖上衣與淺米色長褲。 |
| Mummy 在門旁，態度堅定但不恐怖 | **PASS** | Mummy 站在右側木門旁並伸手示意，表情嚴肅／堅定；沒有恐怖陰影、怪物化或威脅性誇張表情。 |
| 沒有床 | **PASS** | 畫面是客廳與門，沒有床、床墊或寢具。 |
| George 的 T-rex 頭套戴著 | **PASS** | George 頭上清楚戴著恐龍頭套，並可見棕色裂紋鱗片連身裝、背板與尾巴。 |
| George 手持木叉 | **PASS** | George 向上舉著一把棕色、三齒且圓鈍外觀的木製玩具叉。 |
| George 表現 defiant | **PASS** | George 抬頭直面 Mummy，嘴部緊抿、身體前傾並握叉對峙，呈現回嘴／不服的姿態。 |
| Sylvia 穿綠色、戴黃色髮箍、正在觀看且未受傷 | **PASS** | Sylvia 穿整套綠色衣服，頭戴黃色髮箍，站在旁邊看著 George 與 Mummy；沒有接觸、傷口、血或哭泣受傷線索。 |
| Sylvia 比 Mummy 高 | **FAIL** | 以兩人的完整身形與相近地面基準看，Mummy 的頭頂高於 Sylvia，且 Mummy 的頭到腳可見高度更長；畫面讀成 Mummy 高於 Sylvia，未符合 Sylvia > Mummy。 |
| George 是最矮 | **PASS** | George 的頭套頂與身高都明顯低於兩位成人，三人中清楚是最矮者。 |
| 沒有英文文字 | **PASS** | 畫面中沒有可讀英文、字幕或標籤。 |
| 沒有南瓜 | **PASS** | 畫面沒有南瓜桶、南瓜或 Jack-o'-lantern。 |
| 沒有野獸 | **PASS** | 沒有獨立的野獸角色；畫面中的恐龍只是 George 穿戴的 T-rex 服裝。 |
| 沒有船 | **PASS** | 畫面沒有船、水面或其他航海元素。 |

## Overall

**FAIL** — Sylvia 與 Mummy 的可見身高順序錯誤；其餘檢查項目通過。
