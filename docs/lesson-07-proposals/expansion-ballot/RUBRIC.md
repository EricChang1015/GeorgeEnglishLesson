## 評分看這幾項（一樣重）

1. **島上節奏：** 抵岸後是否「當了一陣子王」，而不是上岸兩頁就回家
2. **因果：** 鬧→罰→叢林→船→島上旅程→馴服→狂歡→想家→回航→熱晚飯，有無跳步或重複
3. **對白：** 8–16 字、每頁 3–4 句、emotion 清楚、可朗讀（ORT LV6）
4. **溫暖：** 木叉玩鬧不恐怖；回嘴成立但不傷人；野獸兇而不惡夢
5. **圖文契約：** 每頁必見證據是否畫得出來；木叉／冠／船／鳥燈連續
6. **原創：** 無 Sendak 原句／原角色名；借神韻不侵權
7. **鎖定：** Horn/Beak/Goat、T-rex 頭套不脫、自願留冠、still hot、無人說做夢

## 投票

只能投 **第一名** 與 **第二名**（兩個不同字母）。不要並列。

寫入指定的 `vote-*.md`，格式：

```markdown
# Vote

- first: X
- second: Y
- first_why: （一句，只講文本證據）
- second_why: （一句）
- not_chosen: （另外三份各一句：輸在哪）
```
